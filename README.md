# Bitácora — Introducción a la Física Teórica

Bitácora del curso de Introducción a la Física Teórica.

El objetivo de esta bitácora es registrar el proceso de resolución de problemas
y, especialmente, el proceso de interacción con herramientas de inteligencia
artificial.

La bitácora no busca registrar únicamente las respuestas finales. Se busca
identificar:

- Las hipótesis utilizadas para resolver cada problema.
- Los razonamientos propios antes de consultar a la IA.
- Los prompts utilizados.
- Las hipótesis propuestas por la IA.
- Los errores encontrados.
- La forma en que esos errores fueron identificados.
- Las modificaciones realizadas a las hipótesis.
- La evolución de la solución.
- Las reflexiones personales sobre el proceso.
